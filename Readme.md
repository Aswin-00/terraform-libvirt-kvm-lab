# Terraform Libvirt – Simple KVM VM Testing

## Project Overview

This is a simple testing project created to explore the Terraform `libvirt` provider and understand how to use it to create and manage virtual machines using KVM/QEMU.

The main objective is to learn how Terraform integrates with libvirt and to test the basic configuration required to create a virtual machine.

## Objectives

- Understand how to configure the `dmacvicar/libvirt` Terraform provider.
- Create a virtual disk using the libvirt storage pool.
- Configure a virtual machine with CPU, memory, and disk resources.
- Attach an OS installation image to the VM.
- Configure virtual networking using the default libvirt network.
- Add a graphical console to access the VM.
- Learn the basic Terraform workflow for managing virtual infrastructure.



## Expected Outcome

This is a learning and testing project intended to explore the capabilities of the Terraform libvirt provider rather than to deploy production infrastructure.
